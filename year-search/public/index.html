    About TimeMachine!

    연도와 사이트를 선택해 공개 웹 검색결과를 찾아보는 개인 검색 프로젝트입니다.

    Brave와 Exa의 검색결과를 결합하며, 결과의 날짜와 출처를 함께 표시합니다.

    검색 대상

    전체 웹, Facebook 및 디시인사이드의 공개 색인 페이지를 검색합니다.

    비공개·로그인 필요·미색인 게시물이나 플랫폼 공식 API 결과는 포함하지 않습니다.

    날짜를 확인할 수 없는 검색 결과는 별도로 표시하며, 원문 본문은 게시일 확인 후 제공합니다.

    TimeMachine! · 공개 검색결과를 모아 보여주는 프로젝트
    검색엔진이 날짜를 파악하지 못한 글은 누락되거나 연도가 다르게 표시될 수 있습니다.
